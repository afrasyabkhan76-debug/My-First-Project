# ✈️ Travelling App — Flutter

A modern travelling and destination discovery mobile application built with **Flutter and Dart**.

This project was created as my **first Flutter project** while learning Flutter development, Dart, UI design, navigation, reusable widgets, and application state management.

The app allows users to explore destinations, view destination details, save their favorite places, and explore locations on a map.

---

## 📱 Project Preview

### Home Screen

The home screen provides a simple and clean travel discovery experience.

Users can:

- 🔍 Search for destinations
- 🌍 Explore cities
- ❤️ Save destinations to Favorites
- 🏔️ Browse destinations by category
- 🗺️ Open the map
- 👤 Access the profile section
- 🧭 Navigate between different sections of the app

---

## ✨ Features

### 🏙️ Explore Destinations

Users can browse different travelling destinations with:

- Destination images
- Location information
- Destination categories
- Attractive travel cards
- Favorite buttons

### ❤️ Favorites

The favorite system is functional.

Users can:

1. Open a destination.
2. Click the ❤️ button.
3. Save the destination to Favorites.
4. Open the **Saved/Favorites** section.
5. View their saved destinations.
6. Click the ❤️ button again to remove a destination.

### 🗺️ Map

The application includes a dedicated map section where users can explore destinations on a map.

### 🔎 Search

Users can search for destinations using the search field.

### 🏔️ Categories

Destinations can be explored through different categories such as:

- Mountain
- Beach
- Park
- Nature
- City

### 🧭 Navigation

The application includes bottom navigation for:

- 🏠 Home
- 🧭 Explore
- 👤 Profile
- 🔖 Saved

All navigation buttons are connected to their respective screens.
